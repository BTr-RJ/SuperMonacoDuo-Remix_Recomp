# Project status

Version 0.60 is the current public test of Super Monaco Duo-Remix Recomp for Windows x64,
covering Super Monaco GP (World) and Ayrton Senna's Super Monaco GP II (USA).
See the release notes for [0.60](RELEASE-0.60.md) and [0.50](RELEASE-0.50.md).

Open work, in rough order:

- Remaining approach and curve jitter, signs drawn over passed cars, and distant cars near the end of the road.
- Smoother tunnel lights, tunnel entrance and exit and portals (parts still follow the cartridge's 20 Hz step).
- Calibrating object size and placement to the arcade's perspective.
- Arcade equivalents for more tracks, outdoors and buildings; the sweep so far covers the first track of each game.
- Testing analog steering and pulse pedals on more physical controllers.
- First-time installation on clean Windows machines without C++ tools.
- Playing through more of the achievement sets, and optional leaderboards or an online RetroAchievements link.

Complete static recompilation, equivalence to the arcade game and network play are outside the current scope.
Report reproducible issues with the game, launcher version, settings and a log excerpt
(see [contributing](../CONTRIBUTING.md)); never attach ROMs, generated code or saves.
