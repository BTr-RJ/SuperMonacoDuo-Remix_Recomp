# Controls

Controls for both games live in `.local/controls.ini`, separate from video settings.
Open **Controls** in the launcher to capture keys, buttons and axes, choose the
controller, steering stick and dead zone, clear, restore defaults and save.
Cancel keeps the saved configuration. Esc, Tab and F1–F12 are reserved.

## Defaults

| Action | Keyboard | Xbox-compatible |
|---|---|---|
| Steer | Left / Right | Stick (proportional) or D-pad |
| Menus | Up / Down | D-pad / stick vertical |
| Accelerate | X | A |
| Brake | Z | B |
| Start / pause | Enter | Start |
| Gear up / down | E / Q | RB / LB (R1 / L1) |
| Confirm screens that ask for C | C | X |
| Close the game (launcher stays open) | Esc | – |

Select manual transmission in the game's own menu to use gears. Confirmation
depends on the screen; in GP II the transmission screen may need **C**.

## Analog steering

Both games use the chosen stick for proportional steering, with a 25% initial dead
zone and the cartridge's native turning limits and rate. Pause, keyboard/D-pad input
and disconnection work as before. The vertical axis of the stick only navigates menus; it
sends no brake or gear commands in races.

## Pulse pedals (optional)

Turn on **pulse pedals** in Controls (off by default). R2 accelerates, L2 brakes and the
right stick up/down does the same, race only. The cartridge reads buttons as on/off, so
the pedal is switched on and off several times per frame in proportion to how far it is
pressed. With the option off, a 50% threshold applies.

Not covered by the game: force feedback and wheel/pedal peripherals other than SDL
game controllers.
